SUMMARY

Standard single-cell RNA sequencing (scRNA-seq) workflows convert raw reads into cell-gene count
matrices and then perform filtering, highly variable gene selection, dimensionality reduction, clustering,
and differential expression analysis. Seurat and Scanpy are the most widely used implementations of these
workflows and are generally assumed to yield similar results. Here, we examine the underlying algorithms of
both packages and show that their outputs differ substantially across multiple analytic steps. The magnitude
of Seurat-Scanpy differences is comparable to the variability introduced by sequencing fewer than 5% of
reads or analyzing fewer than 20% of cells. We further find that software version changes can alter results,
particularly in differential expression. Our findings underscore the need for users to critically evaluate anal­
ysis tools and for developers to prioritize transparency and reproducibility.

METHOD DETAILS

Count Matrix Generation
Count matrices were generated using either kb or Cell Ranger. The workflow used in most figures (unless stated otherwise) involved
kb v0.28.0 (kallisto v0.50.1, bustools v0.43.1) and standard arguments. Other package versions used include Cell Ranger v7.2.0 and
Cell Ranger v6.1.2. Reference transcriptomes for kb were built using kb ref with Ensembl release 111, downloaded with gget58; for
Cell Ranger, the 2020-A reference transcriptome was used.
  Read downsampling was simulated with the seqtk package. Cell downsampling was simulated with the ‘‘sample’’ function in base
R. Both read and cell downsampling were performed at the following fractions: 0.64, 0.32, 0.16, 0.08, 0.04, 0.02, 0.01. For each type
of downsampling (read, cell) and each fraction, we downsampled across the following three unique random seeds: 100, 101, 102.
Read bootstrapping was performed with custom code across the following five unique random seeds: 42, 43, 44, 45, 46.

Analysis
All analysis was performed in R markdown files (R v4.3.1) with the reticulate package for Anaconda Python integration (v3.9.18).59
Data processing was performed with dplyr and tidyr.57 All plots, unless stated otherwise, were generated with ggplot2.57 The stan­
dard pipeline for Seurat v5.0.2,60 and Scanpy v1.9.561 were followed for comparison within and between packages.

Filtering
Data were loaded and filtered by UMI counts with the Matrix and DropletUtils packages.62 Filtering by cells and genes was performed
with thresholding with standard values (minimum 3 cells per gene, minimum 200 genes per cell) for full-sized datasets. For datasets
with downsampled reads, these parameters were tuned to maximize the overlap of cell and gene sets between full and downsampled

data. For datasets involving downsampled cells, the minimum cells per gene parameter was tuned to generally maximize the Jaccard
index of gene sets, where the Jaccard index is defined as intersection over union (i.e., the number of elements shared between two
sets divided by the total number of elements between two combined sets). Filtering by mitochondrial gene content was performed
using simple thresholding to remove cells with extremely high mitochondrial gene content, as determined by violin plots (typically >

as determined by biomaRt.63 Filtering results were visualized with UpSet plots using the UpSetR package64 (also used for all UpSet
plots in this study) for the sets of cells and genes, and assessed using the Jaccard index between conditions.

Highly Variable Gene Selection
Highly variable genes were selected based on demonstrating high variance (normalized to mean expression) across all cells. In the
case of Scanpy, subsequent analyses, up to differential expression, were performed exclusively on highly variable gene data. HVG
set similarity was visualized with UpSet plots and assessed with Jaccard index.

Principal Component Analysis
PCA was performed, reducing the dimensionality of the genes to the top 50 PCs. Analysis of PCA results was conducted in three
ways: by overlaying the PCA plots in two dimensions;              by comparing the magnitudes of eigenvalues (Scree plots); and by comparing
                                               √̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅̅
the sines of eigenvectors (where sin(θ) = ± 1 − cos2 (θ) by the Pythagorean identity). The sine of the eigenvectors should be equal
to 0 for identical vectors, and equal to 1 for perpendicular vectors, thus providing a quantification for the similarity of vectors in high-
dimensional space.

Scaling and Regression
Gene expression data were scaled to have a mean of 0 and a variance of 1 per gene across all cells, with user-defined clipping (upper-
bound scaled expression). Optionally, features such as total counts and percentage of mitochondrial gene content could be re­
gressed out during or after this step. Scaling and regression equivalence between packages was assessed by determining the equiv­
alence of PCA embeddings when identical HVGs were used for scaling and regression.

K-Nearest Neighbors and Shared Nearest Neighbors
The cell coordinates from the top 50 PCA embeddings were passed to KNN search algorithms to begin identifying similar groups of
cells. For large datasets, Seurat used the Annoy algorithm through the RcppAnnoy package,34 and Scanpy used NN Descent through
the PyNNDescent package, called by umap-learn. The source code of Seurat’s FindNeighbors internal function calls was slightly
modified to provide an interface for setting the random seed for KNN graph generation with Annoy. SNN graphs were created
from the KNN graphs based on the neighborhood similarity of cells. The similarity of SNN graphs was assessed by computing the
median Jaccard index and the median magnitude in the logarithm of the degree ratio between conditions.
   The maximum Jaccard index Jmax is equal to the degree ratio D = dd12 , where d1 < d2 . The Jaccard index is intersection over union.
The maximum overlap is given by d1 , and the minimum union is given by d2 . This ratio dd12 gives both the degree ratio and the upper
bound on the Jaccard index.

Clustering Analysis
Clustering was performed with the Louvain or Leiden algorithm. Seurat implemented Louvain itself, and Scanpy used louvain-igraph.
Both packages used leidanalg for Leiden.65 Assessment of cluster similarity was assessed visually with alluvial plots generated with
the ggalluvial package,66 and with the ARI calculated with the mclust package.67
  The order of clusters and colors appearing in the alluvial plots was modified in a novel way from the capabilities of the ggalluvial
package. The algorithm for the order of clusters, designed to minimize crossover in the alluvial plot and thus allow general cluster
disorganization to correlate with agreement of clusters between groups, is as follows:

     1. Order the left side from top down by decreasing cluster size
     2. Order the right side such that it shares the nearest available rank to the cluster on the left with which it possesses its maximum
         Jaccard index
     (a) If there are multiple clusters on the right that share the same cluster on the left for its highest Jaccard index, then these clusters
     are sorted by decreasing cluster size

UMAP
UMAP plots were created from PCA-derived nearest neighbor graphs. By default, Seurat uses the uwot package,69 and Scanpy uses
umap-learn.37 Analogous clusters were visually compared for local structure and their relations to neighboring clusters to assess plot
similarity.
   UMAP data extended analysis was performed by constructing a KNN graph from the UMAP space, passing this KNN graph
through Leiden clustering, and further projecting the UMAP-derived KNN graph in UMAP space. KNN construction from UMAP
space was performed with an exact KNN graph implementation from the FNN package, which implements an exact KNN with Kd
trees.70 Leiden clustering was implemented with the bluster package,71 which internally uses an exact KNN algorithm for input to
Leiden, based on the k-means k-nearest neighbor algorithm.72 A further UMAP projection of the FNN-derived KNN graphs was im­
plemented using the uwot package (the same underlying package as Seurat).

Differential Expression
DE analysis was performed on the clustered genes by computing a logFC and p-value for each gene per cluster compared to all other
clusters. Optionally, genes per cluster could be filtered with thresholding for logFC, p-value, or percentage of cells expressing the
gene in a reference group to only select the best markers. We wrote a function to convert the data structure holding the values of
percentage of cells in each reference group expressing a gene from a pandas dataframe to a numpy recarray to make it compatible
with the other DE statistics stored in the Scanpy Anndata object. p-values were adjusted with the Bonferroni or Benjamini-Hochberg
correction. Analysis of significant marker gene similarity (all genes across all clusters with adjusted p-value < 0:05) and marker sim­
ilarity (all cluster-specific marker genes after any implemented filtering) was performed with UpSet plots and Jaccard indices of gene
sets. Analysis of logFC similarity was performed with scatterplots, computation of the CCC, median and mean magnitude of differ­
ence of logFC for analogous marker genes, and a PCA best-fit line. CCC is defined as follows:

QUANTIFICATION AND STATISTICAL ANALYSIS

Data were loaded and filtered by UMI counts with the Matrix package.62 Each pipeline generally consisted of the following steps:
filtering (UMIs, cells, genes, mitochondrial gene content), log normalization, HVG selection, feature regression, scaling, PCA, KNN
and SNN graph formation, clustering, UMAP projection, and DE analysis (Figure S1). Mitochondrial gene content was facilitated
with biomaRt.63 Filtering similarity was assessed by comparing the similarity of cell and gene sets with UpSet plots. Normalization
similarity between packages was evaluated by providing the same data to each normalization function as input and comparing
the similarity of output matrix values. HVG selection similarity was assessed by comparing overlap with UpSet plots and the Jaccard
index. PCA similarity was assessed by overlaying the PCA plots on the first two PCs, comparing the difference in corresponding
eigenvector values on Scree plots, and comparing the sine of corresponding eigenvectors. SNN graph similarity was assessed by
computing the Jaccard index for the overlap in neighborhoods, as well as the median magnitude in the ratio in degree of neighbor­
hoods, for each cell between conditions. Cluster similarity was assessed by visually determining the degree of alignment in alluvial
plots between clusters, as well as computing the ARI. UMAP similarity was determined by visually comparing plots, as well as by
computing KNN graphs from the UMAP space, followed by subsequent Leiden clustering and UMAP projection of these UMAP-
space-derived KNN graphs, with assessment completed as before (Jaccard indices of KNN graph neighborhoods, alluvial plotting,
and ARI computation for clusters, and visual comparison of UMAP plots). DE similarity was assessed by comparing the overlap of the
union of significant marker genes across all clusters between conditions with UpSet plots. When cluster assignments could be unified
between conditions, additional analysis of DE similarity was performed for each marker per cluster by calculating similarity of marker
genes per cluster, by plotting logFC and computing the CCC and PCA fit line, and by plotting adjusted p-value between conditions
and computing the percentage of markers that flipped across the p=0.05 threshold.
    p-values were calculated for each summary statistic with one-tailed t-tests, where the null distribution was created by comparing
bootstrapped datasets to the original dataset (Figure S22). Five bootstrapped datasets were created by sampling reads with replace­
ment to the size of the original dataset, and these bootstrapped fastq files were run through kb count with the same protocol as the
original dataset. Each bootstrapped dataset was compared to the original dataset within Seurat and within Scanpy, utilizing different
random initializations for the steps that involved randomization (SNN graph construction, clustering, and UMAP). A representative
bootstrap seed is shown in Figure S23.
    We model each summary statistic as a pair of independent and identically distributed values from a normal distribution. Specif­
ically, we have (X1 ; Y1 ); …; (Xn ; Yn ), where Xi is the value of comparing bootstrap seed i to the original data using Seurat, and Yi is
the value of comparing bootstrap seed i to the original data using Scanpy. The number of seeds is n (in our case, n = 5).
    We model the deviations of each summary statistic from its optimal value as independent and identically distributed (i.i.d.) normal
random variables. Specifically, we define:
                                                  ϵX = X − ideal   and ϵY = Y − ideal;
where ideal is a constant representing the optimal value for that summary statistic (typically 0 or 1).
 We assume:
              (      )
  • ϵX ∼ N μϵX ; σ2ϵX , i.e., ϵX follows a normal distribution with mean μϵX and variance σ2ϵX ,
              (      )
  • ϵY ∼ N μϵY ; σ2ϵY , i.e., ϵY follows a normal distribution with mean μϵY and variance σ2ϵY ,
     • all ϵX are i.i.d., as are all ϵY .
  Since the sum of two independent normal random variables is also normal, the combined deviation is given by:
                                                             (                      )
                                          ϵX+Y = ϵX + ϵY ∼ N μϵX + μϵY ; σ2ϵX + σ2ϵY :

  Finally, the observed value incorporating the combined noise can be expressed as:
                                                          WϵX +ϵY = ideal + ϵX+Y ;
where ideal represents the combined ideal value, and ϵX+Y accounts for the total noise introduced by Seurat and Scanpy. We use this
W as the null distribution to represent the combined noise introduced by the two packages.
